# Architecture compatibility entry point

This legacy path is retained only as a compatibility entry point. It does not
define architecture, behavior contracts, implementation facts, or live project
state.

Start with the [documentation authority router](docs/README.md), then use the
canonical owner for the claim:

- [Architecture index](docs/architecture/README.md) for responsibilities,
  seams, dependency direction, and invariants.
- [Versioned specification index](docs/specs/README.md) for accepted byte,
  schema, API, and behavior contracts.
- [Legacy migration ledger](docs/migration/legacy-ledger.md) for the historical
  routing of retired chapters.
- [GitHub issue tracker](docs/agents/issue-tracker.md) for open work, decisions,
  blockers, dependencies, and evidence gaps.
