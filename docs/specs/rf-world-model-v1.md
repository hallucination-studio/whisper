## 1. 交付范围与硬切

首个完整单元为20–40平方米、0–2人的房间：手机初始化几何；固定 RF 在手机离场后持续输出存在、人数、位置集合、带歧义的轨迹、可追溯历史、1秒/3秒预测和场景变化候选。精细骨架、更高人数、跨房间唯一身份、未知家具精确重建不属于首版完成条件。

当前设备、固件、UDP 字节、部署位置不变。参考高效果配置增加一个已知固定 Tx 和三个分置的局部相干 Rx 阵列，首个适配对象为 ESPARGOS 类2×4阵列。每阵列独立校准；跨阵列先融合世界坐标概率，不假设共享载波相位。关键区域至少两个非退化有效视角；校准混淆图验证覆盖，不能靠事后删除困难区域达标。当前 ESP 为同一架构提供其实际能力范围内的观测。

旧 Host 统计关系状态、Semantic Session/handoff、Demo 专属投影/分类和旧数据库目标直接移除并由新实现替换。禁止迁移器、旧 schema 导入、兼容 API/别名、双写、影子旧生产系统和 expand–contract。候选新模型的影子验证仍是本规范要求，与保留旧系统双轨无关。

新 Store 使用独立 schema 身份并在新目录显式初始化。运行命令遇旧格式必须拒绝，不能自动升级、导入、修复或删除已有数据库；代码硬删除不授权运行程序静默擦除用户数据。历史 Git revision、已封存执行证据与当前原始设备事实保留其原始含义，不转成新模型证据。

## 2. 使用者行为

1. 安装者扫描房间并确认尺寸、门洞和覆盖，获得稳定世界坐标。
2. 安装者用可见唯一标记注册固定 RF 设备，并保存标记到天线参考的偏移及误差。
3. 单个安装者按站点、姿态、停留和进出提示采集，暂停或追踪重置后可恢复。
4. 安装者将手机留在房外，完成部署条件下的适配和独立核验。
5. 使用者查看当前人数概率、位置不确定性、来源年龄和有效区域，不把无观测误解为无人。
6. 两人交叉或靠近时，使用者看到可信的集合状态及身份歧义。
7. 使用者查看历史和预测，并能区分过去发布结果、当前观测、未来分布和数据缺口。
8. 维护者区分设备故障、正常条件变化与结构变化，再执行有针对性的核验或补扫。
9. 维护者升级/回滚模型组合，服务保护规则防止后台训练抢占正式推理。
10. 开发者重放保留的原始输入并比较相同条件下的模型；原始留存到期后明确提示不可重算。

## 3. 已选定的感知模型

首版模型由 Python/PyTorch worker 实现训练和数值推理；Rust Host 管事实、时间、调度和提交。模型的具体版本、权重、预处理和有限形状写入不可变制品；以下结构不是待选菜单。

| 模块 | 采用的模型/算法 | 约束 |
| --- | --- | --- |
| 慢响应 | 小型 MLP 编码当前绝对幅度、频谱形状和冻结背景集合残差 | 保留静止人体与直流信息；不把全部输入中心化为零 |
| 快变化 | 小型因果 TCN，首版约2秒有界上下文 | 包含实际时间、质量/缺失掩码；当前新块之外的历史不构成额外独立证据 |
| 阵列路径 | 合格角度/时延估计＋地图路径解释＋小型人物散射偏差头 | 最强峰不等于人体，普通单路径 ESP 不开启 AoA |
| 空间融合 | 地图网格查询与跨源注意力 | 保留各源适配前端及资格，旧数据不冒充当前视角 |
| 当前世界 | 完整0–2人无序集合的因果条件 CRF/联合网格模型 | 一个联合后验派生存在、人数、位置；对称二人交互头 |
| 短期预测 | 监督得到的稀疏真实转移 `T_phys` | 只滚动真实动力学，不滚动推断恢复项 |
| 比较基线 | 先验/保持/常速度、统计＋线性/树/RBF、随机特征、小 TCN/GRU、适用 RuView 和 OpenCSI | 同硬件/地图/标签/适配预算；不选择弱模型代表项目 |

不引入 LLM 生成世界事实。RSSM、Mamba、MoT、通用预训练、完整 CSI 逆渲染、压缩和蒸馏均非首版依赖。Luna/Sol 是执行开发与审查任务的代理模型，不参与 RF 推理。

## 4. 测量、坐标与校准

原始数据与派生测量分开。每项保留源实例/boot、Tx、PHY、信道/带宽、真实路径、原生样本/LTF、原始字节、采集 tick、接收时间、质量、实际增益信息及格式版本。未知频率轴保持 opaque，重复 LTF 不制造天线。未采集、丢失、无效、插值和训练掩码分别表示。

测量片段以真实事件身份组装，组装键不能只用短序号或到达邻近。`AssemblyClose` 持久化成员与缺失；关闭后晚到作为新事实，不修改旧测量。每队列/组装限定数量、字节和等待时间。

`PortMapping` 区分 Tx stream/Rx chain 与物理天线；未知预编码不授予 Tx 几何。`TimeRelation`、`PhaseRelation` 与 `Geometry` 分开记录来源、范围、误差、有效期和 epoch。时间同步不授予相干；包内相干不授予跨包相位稳定。模型激活和每个窗口分别检查算子所需资格。

手机首版为 Swift/SwiftUI、支持 LiDAR 的 iPhone/iPad、RoomPlan/ARKit。扫描后延续合格 ARSession，固定手机取得 RGB/depth 与脚点/站点监督，ARBodyTracking 非必需。手机位姿不是人体根节点，未看见的人不能标为空房。追踪重置后必须重定位；最终地图和历史相机位姿使用一致变换。

保留 SceneSnapshot、CalibrationBundle、SupervisionSegment：坐标/几何误差、设备参考、相机内参、样本时间、追踪/深度质量、可见性、标签来源及误差。手机本地缓存后可靠上传，上传流量不成为 RF 标签捷径。 手机使用独立companion通道：Host本地发起一次性配对，手机固定服务端身份并建立加密连接，完成有界双向时钟采样和采集后的可恢复封存上传。该通道仅有candidate制品导入权，无current/模型激活权限；提供同格式本地导出与Host显式导入作为传输恢复路径。所有入口按数量/字节/时间限额，配对身份不复用现有设备密钥，不把旧世界查询API直接开放到LAN。

手机↔Host 使用双向偏移/漂移估计；固定 RF→Host 的单向 UDP 不足以确定未知固定延迟。标签预算保守覆盖地图、注册、人体估计及最大速度×时间误差。优先静止监督；动态标签需合格时间/空间误差。

单人核心操作目标25分钟：扫描/注册5、固定手机采集8、无手机适配4、留出核验/空房5、恢复余量3。训练等待与开发数据另计。真实多人基础数据和场地二人核验另计人员劳动；25分钟不包含全部多人或骨架能力。

## 5. 唯一联合状态与预测

网格约0.5米，80–160个有效格子，包含沙发/床上人物根节点的地面投影，不采用仅导航可行走掩码。状态为 `∅`、`{i}`、`{i,j}`（i≤j，允许同格）与 overflow。完整状态数 `1+G+G(G+1)/2+1`；G=160为13,042，首版不依赖 beam 剪枝。速度、活动和姿态是联合状态的条件输出，只有对应监督和验收合格才开放，不与全部网格状态作笛卡尔展开。

每个250毫秒不重叠新证据块最多推进一次。网络输出条件势 `u_t(S)`，递推 `α_t ∝ exp(u_t) · (α_(t−1) T_infer)`；采用 logsumexp 归一化。`T_infer=(1−ε)T_phys+ε·1πᵀ`，均规范化；真实转移稀疏，恢复为低秩项，禁止13,042平方稠密矩阵。完整递推展开训练，每前缀集合 NLL/Brier 校准，不能把单帧后验反复乘作独立似然。

无任何合格新 RF 时 `u_t=0`，只传播时间与不确定性；时间传播本身也经过C持久化后继checkpoint与相应世界/历史结果，不能只留在内存。转移按实际Δt参数化，不能把不规则间隔一律当250ms。缓存的 TCN 不生成新观测势。重复块不推进。部分源旧上下文带年龄/缺失，不能增加当前有效视角。

面积先验按真实格面积归一化；二人无序权重为 `(2−1[i=j])w_iw_j`，再乘人数先验。二人关联保留两个指派分项，再合并无序状态；轨迹只读取该模型转移，不追加第二独立跟踪滤波。无法区分同格二人时不虚构分离坐标。

冷启动保留空房/有人候选；静止由当前慢响应支持。缺口不生成无人证据，恢复不自动登记为进入/退出。身份仅表示连续轨迹，不能声称自然人身份。三人及以上进入 overflow。1秒/3秒预测仅对当前联合分布滚动 `T_phys`，不读取未来 RF，不把恢复跳转当真实运动。

## 6. 数据与场地维护

开发数据跨人物/日期/房间和实际参考硬件；每房间只拟合有限背景、空间参考和小型适配头。局部手机标签用兼容联合集合概率边缘化；全屋人数另行确认；软标签联合保留共享坐标/时间误差与个体误差。真实二人/overflow 数据不可由单人 CSI 相加替代。

正式背景为有独立来源的有限条件集合。只在经过验证的范围内估计正常扰动；候选背景不能凭模型自报空房晋升。持续未解释残差同时考虑设备、人体、环境和结构解释。

局部补扫后全房 RF 兼容性待核验，以独立空房、哨兵站位和静止片段恢复合格源/任务。地图、校准、预处理和模型组成完整候选制品，离线及有界影子验证后原子激活。无告警不能刷新几何最后确认时间。坐标或状态格式不兼容时重新 warm-up。

## 7. 不可变请求与提交

`ModelRun` 固定权重、算法/预处理/归一化、输入输出与标签语义、校准应用与容忍策略、融合策略、形状上限、状态格式。`InputManifest` 固定源 boot、原始分段/记录、测量关闭、每个原始时钟域范围、Profile/适配器、PortMapping、TimeRelation快照及误差、PhaseRelation/Geometry/校准引用及有效范围、掩码和预处理版本、因果截止和原始摘要。单个逻辑cutoff不能替代多时钟范围。大张量在 writer 外物化，规范字节摘要派发前持久登记。重物化只能用冻结引用；不一致终结任务。

同状态流最多一个未决计算与一个最新待处理上下文。请求/返回均绑定 run、epoch、request ID、cutoff 和已提交前驱摘要。跳窗/超时关闭 epoch并重新 warm-up，记录覆盖损失；后继不读取未提交状态。合法通道排列与容忍范围内时钟拟合不每包重置；模型语义、源 boot、真实几何/相位/端口变化或不可接受缺口结束受影响连续性。

| 提交 | 同一 SQLite 事务的权威内容 |
| --- | --- |
| A | 原始有序事实、设备 admission/replay 所需状态及重建来源 |
| B | 确定性 CPU 投影、窗口游标、不可变输入与请求描述符 |
| C | 第一个合格结果、后继 checkpoint、请求终态、状态游标、世界投影、派生日志、有效期与 watermark |

checkpoint 首版即存在，使用有界 SQLite BLOB：完整联合分布、有限关联、块游标、前驱摘要、场景/校准/模型引用与状态格式；G=160的FP32联合分布约51KiB。TCN上下文由冻结输入重物化。checkpoint自包含，祖先摘要不形成无限原始保留链。

ACK 在C后。消息格式/大小检查后先查终态；已提交的相同payload重试返回原回执，即使现在超时。冲突payload不替换事实，保留有界冲突并隔离worker。非终态才校验run/epoch/前驱/截止/资格；未知请求拒绝。成功与超时由writer串行裁决，timeout/cancelled/superseded/invalid均持久终态。

## 8. 恢复、服务与留存

重启完成有界 A-only 尾部的 B，结束旧未决在线任务，提交新 epoch与Unknown，再接新数据 warm-up。旧世界是历史，不能用不计停机的旧SessionTime恢复current。在线年龄用单调时间；UTC只用于有误差的外部关联。

没有新包也提交结果绑定的 Expire 和 watermark。旧Expire不覆盖新结果；查询检查当前run/epoch、资格、覆盖与新鲜度，返回as_of、来源时间、有效期。客户端过期/断连显示历史或失联。派生历史回放不派发在线任务，离线重算用另一个run。

入口、源、组装、张量、结果、checkpoint和事务按数量与字节有界，尺寸乘积检查溢出。writer在接收/结果/控制间有限批次轮转；大解析不占写事务。OOM/NaN/Inf/错误形状隔离为模型失败，原始接收继续；持久化/写入权威失败停止接纳并报缺口。

正式接收/持久化、观测推理和世界发布优先；手机导出、离线重放、影子推理、训练各自限制数量、字节及计算额度，不共用无界后台队列。上线后重训练默认独立GPU/训练环境；单GPU只有预先验收的CPU核心服务才能在声明降级范围内让出GPU，否则禁止训练抢占。训练读取封存语料，不持有在线SQLite长事务。初次上线前可用同GPU训练。

默认容量规划为24小时滚动原始数据与30天派生历史，实际按目标Host配置并资格验收。原始8 Link×100Hz×512字节约35.4GB/天；三阵列100Hz×8路径×114复数×8字节约189GB/天只是张量容量算例，不是实际线缆格式。预算须包含索引和封存语料。

派生结果日志独立于原始分段删除：每C保存已发布人数分布、网格边缘量、实体/关联、质量/有效期/失效事件、来源摘要/版本；单条编码上限4KiB，4Hz约1.42GB/天；超限制品不激活，不能静默截断字段。它不保存完整联合相关性。删除原始分段前封存结果并释放活动请求/checkpoint上下文/训练引用；原始到期后仍可查发布历史，原始重放和重新推理明确不可用。只有closed且无活动请求、checkpoint重物化、训练或封存引用的分段可清理，持久记录留存空洞。低水位先停非必要导出/离线重放/影子/训练；耗尽则停止接纳并公布缺口。历史查询包含已发布活动区间、进出/场景变化事件、观测空白及身份歧义；1秒/3秒预测保持自身时间与来源，不冒充历史真实轨迹。

完整run/人员/日期/房间先分区再切窗，训练区拟合变换，validation选模型，最终test锁定后仅用一次。无目标适配、独立无标签适配、同预算有标签适配及使用完整测试输入的转导分开报告。适配与验收分离；参数搜索、随机种子和预训练成本披露。冻结对手代码/权重/可比任务/坐标/因果上下文/数据接触与最小实际改善、非劣界、事件定义、样本量。不能比较不存在的任务或以不合格弱实现代表RuView。

Unknown、跳窗、未输出计覆盖和漏检；空房率仅用独立确认空房时间，并另报不可用率。按独立日期/房间报告不确定性，连续帧不是独立实验；同硬件算法和新增硬件收益分开。测试后修改需要新测试集；未达原目标不能通过缩小声明自动宣告完成。

## 10. 必需反例与交付依据

最高共同集成测试边界为“合法输入或明确故障 → 已提交世界/历史查询与有效期”；手机另有“扫描/标签包 → 可激活校准”的入口。内部只为物理解析、集合递推、协议编解码和事务边界保留必要纯函数/故障注入检查，不构造平行权威模型。

必须首先验证硬切：预置非空旧schema数据库及WAL/SHM/旁文件，init/serve在任何写事务前拒绝，所有既存字节保持不变，无DROP/DELETE/VACUUM、无同路径初始化fallback；未知/损坏格式和已存在目标也遵守拒绝与no-replace。保留原生固定C/Rust向量与认证/重放行为的回归。

还必须覆盖：冷启动静止、缺包期间进出、同格与二人交叉、手机离场、网络负载、背景/家具变化；metadata-only/常量/打乱CSI及同历史不同未来；非相干混合/分包/排列/校准过期；A/B/C/ACK崩溃、重复/冲突/迟到、无包到期/旧Expire、冻结输入重物化；GPU故障、过载/慢磁盘/耗尽、原始删除后的历史和模型切换。

确定性与故障测试只能证明实现行为；真实标签、参考硬件和长期实验承担效果验收。设计接受允许实施，不代表已训练、已交付或已经胜过开源基线。
