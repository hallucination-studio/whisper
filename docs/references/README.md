# External references

References preserve source identity and provenance. They do not select a model
or establish Whisper performance by being listed.

- [Native-frame provenance](native-frame.md) retains the existing ESP-IDF,
  firmware build, provisioning and protocol source pins.
- [RF world-model sources](rf-world-model.md) records the sources used by the
  user-frozen RF design and its accepted implementation specification.

Earlier exploratory source catalogs are available in Git history. The selected
product algorithms are owned by the RF specification, not by a catalog of
possible foundation models.
