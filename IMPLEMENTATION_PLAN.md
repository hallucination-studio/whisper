# Implementation plan compatibility entry point

This legacy path is retained only as a compatibility entry point. It no longer
owns a live implementation plan, sequencing, progress or status, blockers, or
acceptance evidence.

- [GitHub Issues](docs/agents/issue-tracker.md) own live work, decisions,
  dependencies, blockers, and evidence gaps.
- [Versioned specifications](docs/specs/README.md) own accepted behavior and
  completion criteria.
- The [roadmap](docs/ROADMAP.md) owns future intent that has not become an
  accepted contract.
- The [legacy migration ledger](docs/migration/legacy-ledger.md) records where
  the retired plan chapters were routed.
